🦀 Pinch Points 🦀 a crab-routing video game

One to six players, on the couch or over the wire.

macOS · Linux

curl -fsSL https://agourlay.github.io/pinch-points/install.sh | sh

Installs to ~/.local/bin · Read the script

Windows (PowerShell)

irm https://raw.githubusercontent.com/agourlay/pinch-points/master/site/install.ps1 | iex

Installs to %LOCALAPPDATA%\Programs and adds it to your PATH · Read the script

Or download a release, or with Rust: cargo install --locked pinch-points

What's in the box

  • Tide Pool 100 solo puzzles
  • Turf War 2-6 on one couch
  • Beach Lobby 6 over LAN
  • Driftwood level editor
  • Beach Day score attack
  • Daily Challenge same for everyone
  • Replays shareable as text
  • 50 trophies to go after
